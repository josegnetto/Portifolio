# Portfólio — José Neto

Site de portfólio de José Neto, desenvolvedor web em João Pessoa (PB).
Sites sob medida para empresas, com orçamento personalizado para cada cliente.

## Estrutura

```
index.html     estrutura e conteúdo da página
css/style.css  estilos (cores, tipografia, layout, responsividade)
js/main.js     efeitos: luz que segue o mouse, animações de entrada, barra de progresso
favicon.svg    ícone da aba
og-image.jpg   imagem de prévia ao compartilhar o link (1200×630)
assets/        imagens dos projetos (prints)
vercel.json    configuração de deploy na Vercel
```

## Rodar localmente

```bash
python3 -m http.server 4321
```

Depois abra http://localhost:4321.

## Adicionar um projeto

No `index.html`, dentro da seção `#projetos`, copie um bloco
`<article class="card project ...">` e troque título, descrição e link.

## Deploy

Hospedado na Vercel em https://joseneto-dev.vercel.app, com deploy automático a cada push na branch `main`.
